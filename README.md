# Controle de Descartes de Hortaliças

Projeto desenvolvido com base na história de usuário:

> Como um produtor rural, eu quero registrar as perdas de hortaliças especificando a quantidade e o motivo do estragamento, para que eu consiga identificar o volume de desperdício em cada lote.

## Critérios de aceitação atendidos

- Seleção da hortaliça.
- Informar quantidade descartada.
- Seleção obrigatória do motivo.
- Motivos: deterioração natural, pragas, doenças, danos no transporte, armazenamento inadequado e outros.
- Dedução imediata do estoque.
- Bloqueio de quantidade maior que o estoque disponível.
- Registro de data, hortaliça, quantidade e motivo.
- Histórico dos descartes.
- Total de perdas e estoque atual.

## Como executar

Abra o arquivo `index.html` no navegador.

Os dados ficam salvos no `localStorage` do navegador.

## Tecnologias

HTML5, CSS3 e JavaScript.
